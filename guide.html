RcHarness · 安装与配置

把遥控器接到电脑上

当前指南适用于 macOS。从下载与配对，到按住说话和常用语配置。
按顺序完成配置，也可以直接跳到需要的部分。

优先从 GitHub Releases 下载应用压缩包，解压后将 RcHarness.app 移入「应用程序」。第 02 节仅供需要源码构建的用户参考。
开始前准备源码构建配对与授权按住说话应用与方案常用语配置排查问题

01 · 开始前准备

  • Apple Silicon（M 系列芯片）Mac，运行 macOS 14 或更高版本。
  • 仅源码构建需要 Xcode 与 Swift 工具链；当前 CI 与发布使用 Xcode 27.1 / Swift 6.4。
  • 仅源码构建需要 RcHarness 源码工作副本。项目为 Swift / SwiftPM 原生 macOS 应用，没有第三方 Swift 依赖。
  • 支持的蓝牙遥控器：小米蓝牙遥控器 2（RC001-MS）、2 Pro（RC003-MS）或 Google Chromecast（G9N9N）。Google G9N9N 仅验证拼多多店铺「金利达数码科技大全」销售的产品，其他店铺或批次尚未验证。详见推荐页面。
  • 如需语音转文字，另外准备语音输入工具，并确认可以指定麦克风与触发快捷键。

02 · 构建本地 App

在终端中进入 RcHarness 源码根目录，执行测试与构建。以下命令生成本地使用的 Apple Silicon 应用，不会发布安装包。

# 先进入你本机的 RcHarness 源码目录
cd /path/to/RcHarness

# 先设置有效的 Apple 签名身份（不要填 -）
# 在终端运行 security find-identity -v -p codesigning 查看可用身份
export RC_HARNESS_LOCAL_SIGNING_IDENTITY="你的 Apple 签名证书名称"

# 运行 Swift、驱动和音频探针测试
scripts/test_all.sh

# 构建原生 macOS App
scripts/build_app.sh .build/RcHarness.app

# 打开 App
open .build/RcHarness.app

音频探针需要相应录音权限与已安装的回环设备；环境不满足时会跳过。构建脚本默认生成 Release、arm64、最低 macOS 14 的 App，虚拟麦克风组件随 App 打包。

签名与系统权限

按当前源码 README 的构建要求，先将 RC_HARNESS_LOCAL_SIGNING_IDENTITY 设置为有效的 Apple 签名身份，值不要使用 -。应用与随包麦克风驱动应使用同一身份，并通过 codesign --verify --deep --strict 校验。如果变量只配置在 ~/.zshrc，非交互构建时需通过 zsh -ic 加载。签名身份发生变化后，可能需要重新授予输入监控和辅助功能权限。

本地构建不等于已通过 Apple 公证的分发版本。分发签名、公证和公开下载不在本指南范围内。

03 · 配对与授权

  1. 打开 Mac「系统设置 → 蓝牙」，按遥控器自身的配对说明完成配对。
  2. 启动 RcHarness，在「设置 → 权限」中按提示允许「蓝牙」「输入监控」和「辅助功能」。
  3. 点击 App 右上角设备卡片，或进入「连接与语音 → 更换遥控器…」，选择对应型号。检查设备状态，并打开「启用遥控器映射」。
  4. 在「按键」页尝试方向键、确认、返回和自定义快捷键，确认按键响应符合预期。

RcHarness 关闭主窗口后仍会驻留菜单栏。点击菜单栏图标可重新打开主面板。更换遥控器型号时，会加载该型号独立保存的全局按键、键位方案与 Harness 绑定。

04 · 配置按住说话

RcHarness 负责把遥控器的声音传到 Mac，语音输入工具负责识别文字。两者需要分别完成配置。

  1. 在「连接与语音」中安装随 App 提供的麦克风组件。首次安装需要管理员授权。
  2. 在语音输入工具中，将麦克风明确选择为「RcHarness 遥控器麦克风」。
  3. 在 RcHarness 的「按键」页点击语音键卡片，配置与语音输入工具一致的长按快捷键。「设置 → 全局按键」用于选择普通全局实体按键，语音键的快捷键在按键页单独配置。
  4. 允许 RcHarness 与语音输入工具所需的麦克风权限，在真实输入框中测试「按下 → 语音浮窗 → 识别文字 → 松开结束」。

当前支持的三款遥控器松手后都会停止收音，仅可启用「长按」模式。「点按」快捷键可以保存，但不能在这些遥控器上启用。

微信输入法参考配置

可将微信输入法的「按住说话」与 RcHarness 的语音触发按键都设为「地球键（Fn）」，关闭 Fn 点按模式，麦克风选择「RcHarness 遥控器麦克风」。语音浮窗出现且产生识别文字，才表示完整链路已就绪。

RcHarness 不会替你安装第三方语音输入工具，也不会自动更改系统默认输入或输出设备。不同工具的快捷键行为与兼容性需实际测试。

05 · 定义你的工作流

  • 按键：对照遥控器图片与按键连线，为普通按键配置单击、双击、长按，录制快捷键或绑定常用语、鼠标动作和组合动作。
  • 键位方案：新建、复制、重命名当前遥控器的整套按键配置，并查看 Harness 绑定状态。每个型号的方案分别保存；默认方案、内置应用同名方案及已绑定的方案不可删除。
  • Harness：为 Codex、Claude、Cursor、DeepSeek、WorkBuddy 等内置应用或自行添加的应用绑定当前遥控器的方案。同一方案可被多个应用共享；列表同时显示运行状态。停用会保留绑定；移除 Harness 会解除绑定，但保留按键方案和应用本身。
  • 运行列表：默认单击电源键，打开已启用且正在运行的 Harness。用左右方向键选择、确认 OK 切换应用；按返回或主页关闭列表。电源键默认双击为区域截图，长按进入原生模式。
  • 常用语：从「按键」页底部进入，管理内置的 16 条双语提示语，分别编辑两组标题与正文，再绑定到遥控器按键。详见下节。
  • 组合动作：按顺序加入受支持的本机动作与等待时间，再绑定到按键。
  • 配置备份：在「设置」中导出配置，备份各遥控器的全局按键、键位方案、Harness 应用与绑定，以及组合动作、常用语和按键分配。导入时先核对预览，再确认替换；每次替换前自动保留一份配置，可通过「恢复替换前配置」恢复。外观、启动选项、音频设置和使用统计不在导入范围内。

电源等普通全局按键与语音全局按键，对当前遥控器的所有方案和 Harness 生效；不同遥控器分别保存。前台应用匹配到已启用的 Harness 时，应用会自动加载绑定方案；未匹配时使用默认方案。

06 · 配置常用语

常用语是「按键」下的子页面，从按键映射底部的「常用语」进入。内置 16 条中英文提示语，可编辑、删除和排序；每条的两组内容也可改为任意语言。

  1. 在「常用语库」中选择条目，分别编辑右侧「内容 1」与「内容 2」的标题和正文，修改自动保存在本机。
  2. 在左侧「按键分配」中选择要配置的位置，为它分配一条常用语。选择弹窗支持搜索两组标题和正文，也可选择「不分配」。
  3. 返回「按键映射」，将「唤出常用语」动作绑定到一个可配置的普通按键手势。此动作不支持作为组合动作步骤。
  4. 在目标应用的文本框中，用该按键唤出浮层。单击方向或确认键输入内容 1，双击输入内容 2；预设分别为中文与英文。成功输入后浮层关闭。
  5. 使用返回、主页、菜单或 Esc 关闭浮层。常用语按键分配在各遥控器和方案间共用，不会改写原有按键方案。

首次使用且五个位置均未绑定时，推荐分配为：上「继续执行」、下「检查结果」、左「解释一下」、右「修复问题」、确认「确认方案」。已有任意位置绑定时保留你的配置。

删除与撤销

被按键或组合动作引用的常用语，删除前会显示影响范围。确认删除后可从工作区底部撤销；撤销入口在本次运行期间保留。关闭撤销提示、成功导入或恢复配置会清空撤销记录。

07 · 遇到问题时

按一次却出现多个动作？

确保同一遥控器只由一款映射软件处理。退出 Joy Harness 等其他映射程序后，在 RcHarness 中关闭再开启「启用遥控器映射」，再重新测试。

长按电源键后，按键映射停止了？

默认长按电源键或单击菜单键会进入原生模式。请在主面板重新打开「启用遥控器映射」，或从菜单栏的模式项恢复映射。

遥控器连接了，却没有文字？

蓝牙连接与音频计数正常，不能单独证明输入法正在听写。请逐一检查麦克风选择、两端快捷键、系统权限，以及目标 App 是否有当前可输入的文本框。

升级后快捷键不工作？

如果本地构建的签名身份发生变化，需要在系统设置中重新授予当前 App 输入监控与辅助功能权限，再重新打开应用。

配置与诊断在哪里？

配置与常用语保存在当前 Mac。音频诊断日志位于 ~/Library/Logs/RcHarness/audio.log，只记录计数、时延与状态，不保存音频或听写内容。系统日志使用 subsystem vip.tokenzz.rcharness。

本指南依据 RcHarness 的功能与源码整理。硬件语音链路、遥控器固件和第三方 App 组合可能影响实际体验。
