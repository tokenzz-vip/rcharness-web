# RcHarness 网站优化记录

日期：2026-11-10。内容基线：[RcHarness v0.2.0 / 1067cae](https://github.com/tokenzz-vip/RcHarness/releases/tag/v0.2.0)，对照同级软件仓库 README、docs/behavior.md、DefaultPhrases.swift、SettingsStyle.swift 与安装的 v0.2.0 应用。

方法：[unslop](https://heydamir.design/unslop)，作者 [Damir Sokolovsky（@heydamir）](https://x.com/heydamir)，CC BY 4.0。保留其署名；本记录是针对 RcHarness 的应用结果。

## 原页面审阅

- 首屏口号泛化，不能直接解释蓝牙遥控器如何操作 Mac
- 首屏径向紫色背景、环形轨道、倾斜窗口与浮动卡片竞争注意力
- 配色在页面、阴影、卡片与多个文字角色中重复使用近似紫色
- 英文大写标签带较宽字距，部分界面说明仅 7–10px
- 波形持续循环，按钮悬浮位移与有色阴影缺少实际状态依据
- 常用语截图与指南落后于 v0.2.0 的按键分配和两组内容
- 自定义 Harness、配置导入预览和恢复未被充分说明
- 页脚 Mac/Win 表述与当前 Mac 下载页面的系统说明不一致
- Google G9N9N 未注明已验证产品范围

## 已确认的方向

- 产品：用蓝牙遥控器操作 Mac 上的 AI 应用
- 性格：克制、准确、顺手
- 世界：最新版软件的原生 macOS 灰阶、系统字体与蓝色操作提示
- 重点：真实软件界面，以及常用语的配置与输入方式
- 标识细节：遥控器方向键与快捷键键帽

保留真实应用 Logo、现有栏目顺序、三款设备及原有软件推荐。不增加未经证实的功能、性能或用户数量。常用语展示采用软件实际截图，不另行绘制模拟界面。

## 九轮调整

1. 间距：采用 4px 网格，统一 24/32px 卡片内边距、44/48px 主要操作控件和段落分组；遥控器热点继续按真实图片比例标定
2. 颜色：浅色 #fafafa、深色 #141415；三档中性文字；#175dcc 操作蓝在浅色底约 6:1，深色使用 #8ab8ff；移除紫色光晕和有色阴影
3. 图标：保留单色线性图标，18px / 1.5 描边；保留真实应用 Logo；箭头与键帽作为实际操作提示
4. 文案：首屏直接写明产品用途，补全常用语、双语内容、自定义应用和导入恢复；更新系统、签名、语音配置及硬件验证范围
5. 字体：保留 macOS 系统字体，400/500 常规字重，Logo 600；说明不低于 11px，常规正文 14–16px；去掉大写英文装饰标签和小字负字距
6. 布局：保留首屏左右分栏，真实软件截图占更大空间；手机首屏显示较简单的真实常用语浮层；推荐页按硬件、软件阅读顺序排布
7. 细节：控件 8px、卡片 16px、面板 20px 圆角，内嵌层级相应缩小；键盘焦点、选择、悬停状态明确；小浮层在截图展示区居中按比例显示
8. 视觉：更新 22 张深浅色 WebP 截图与社交分享图；使用软件实际界面、真实设备图和应用图标，不需要生成图片，因此无图片生成提示词
9. 动效：移除所有循环波形与悬浮装饰；仅保留 160ms 的颜色、边框与轻微按压反馈；支持减少动态效果偏好

## 常用语展示修正

按用户反馈移除自绘十字形按键演示及其 JavaScript、CSS，替换为支持深浅色的真实常用语设置截图。页面统一称为「常用语」，相关双语预设与内容操作注明 macOS 版，避免将模拟样式或平台差异当成软件现状。

## 常用语圆盘交互

按用户进一步确认，保留原有常用语点击和中英文内容预览，图形按真实项目 PhrasesPage.swift 的 PhrasePadSector、PhrasePadLayout 与 PhrasePadKeyStyle 实现：四个 87 度环形扇区，半径 105，内径比例 0.36，独立的直径 66 确认键，以及同源的标签坐标。扇区路径同时作为点击区域，中心和扇区之间的间隙不触发操作。正文取自 DefaultPhrases.swift；支持 Enter、Space 和方向键，提供选择与键盘焦点状态。

## 推荐页布局还原

按用户要求继续恢复至 Git 已提交版本的推荐页布局：标题「推荐」，桌面采用左侧硬件、右侧软件的分栏，恢复原版卡片尺寸、筛选与响应式样式。推荐页专用 CSS 与 HEAD 一致。保留 Vokie 的移除及筛选数量 5/3/2，保留已核验的 G9N9N 验证范围、当前语音配置说明与全站导航、下载信息。首页和指南等其他页面不做回退。

## 推荐软件更新

微信输入法移至原 Vokie 的主推荐卡片，保留原来的图片区、大标题和官网入口；下方两张小卡片为豆包输入法与新增的讯飞输入法，筛选数量更新为全部 6、硬件 3、软件 3。推荐页 CSS 和左右分栏布局不变。

微信输入法图标来自官网引用的腾讯 CDN（https://cdn.weread.qq.com/web/wetype/favicon/icon-152.png），保存为 assets/recommendations/weixin.png，152 × 152 PNG。微信语音转文字与桌面平台信息核对官网 https://z.weixin.qq.com/；讯飞输入法链接及输入方式核对官网 https://srf.xunfei.cn/。未新增硬件兼容性或性能承诺。

验证：构建、JavaScript 语法、差异空白检查通过；深浅色各检查 320 / 390 / 768 / 960 / 1440px，无横向溢出、图片加载正常；主卡片与软件顺序符合要求，键盘筛选及数量播报 6/3/3 通过。完成桌面视觉复核。

## 首页按平台下载

首页首屏将「获取应用」改为「下载 Mac 版」与「下载 Windows 版」两个明确的平台入口。Mac 按钮直达 GitHub v0.2.0 的 macOS arm64 ZIP，注明「仅 Apple 芯片 · macOS 14+」；根据当前公开发布信息和本地 Windows 仓库状态，Windows 暂未提供公开安装包，按钮禁用并注明「Windows 11+ · 仅 x64 · 暂未发布」，不设置无效下载链接。「查看软件界面」移至下方文字链接，与原有常用语链接并列。其余页面与下载弹窗不改动。
